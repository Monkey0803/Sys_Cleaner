# Sys Cleaner

Sys Cleaner 是支持 macOS 14 及以上版本的原生文件清理应用，使用 SwiftUI 编写，提供简体中文和英文界面。

## 功能

- 空间逐层分析、只读的已挂载卷概览和带动画的容量饼图；点击扇区或图例深入查看文件夹、预览文件。支持大文件筛选和按内容哈希确认重复文件。
- 下载项页面只扫描当前用户的“下载”文件夹，递归列出普通文件并区分安装包、压缩包及未完成下载；可搜索、排序、预览并逐项移入废纸篓。未完成下载不能选择，也不提供永久删除。
- 清理总览汇总本次打开 App 后已扫描的可操作候选，显示本机与 iCloud 本机副本的容量估算、各分类扫描位置及不完整原因；同一路径或已列出文件夹的子项只计一次。统一审阅清单可搜索、按分类／操作／风险筛选并分页浏览全部候选，再跳转到原页面逐项勾选和确认；总览不直接清理。
- 目录容量统计完整的空间分析扫描在本机保存最多 20 份目录快照，并对同一扫描根目录、相同排除路径的两次扫描比较增长。根目录直属文件夹全部记录，深层目录保留最大的 2,000 个；未记录的深层目录不作增长判断。单独文件的展示上限不影响目录容量记录；目录读取失败的扫描不写入历史。
- 审阅当前用户的缓存和日志；Xcode 概览分别扫描 DerivedData、归档、模拟器设备、模拟器运行时和 iOS 设备支持文件，逐类显示估算大小、状态与耗时。审阅清单按清理方式列出较大项目：构建目录按可靠元数据归组，显示合计大小和最近活动，展开后可逐项选择移入废纸篓；已关闭的模拟器设备须单独确认且不能通过废纸篓恢复，归档、运行时和设备支持文件只读。各项显示可获取的真实路径并提供访达入口；缺少路径时明确提示。DerivedData 支持自定义路径、项目搜索、归属筛选与排序。运行时显示同标识设备数量，并在多份镜像共用标识时提示无法确定设备所用构建；移除运行时请到 Xcode 设置 > 组件中审阅。共享缓存、DeviceLogs、文档数据、Products 记录、DVTDownloads 与 XCTestDevices 显示逻辑大小、磁盘占用估算、扫描状态和访达入口；其中四类已验证缓存可逐项选择移入废纸篓。

Xcode 概览列出各扫描来源，包括已确认的 DerivedData 共享缓存和其他只读 Developer 目录。“扫描完成”仅适用于列出的来源。自定义 DerivedData 和归档路径可分别在项目页、归档页手动添加；归档始终只读。重叠或符号链接来源会被拒绝，以免重复计量。多个 Xcode 版本可能共用同一位置，因此不推断版本归属，也不将各类别估算相加为总占用。

完整的 DerivedData 扫描最多在本机 `~/Library/Application Support/Sys Cleaner/xcode-project-history.json` 保存 30 份项目大小快照。项目页仅在扫描路径与排除项一致时，与上次完整扫描比较有元数据归属的项目；不完整扫描不保存快照，来源或项目元数据变化时明确显示无法比较。未知项目不归入项目历史，项目未再出现也不能证明数据已被删除。
其他 Developer 位置仅按确切目录名识别。用途说明来自路径和已观察到的内容，不代表已经证明可重建；这些目录保持只读。四类共享缓存已在本机多个 Xcode 版本的隔离构建中重新生成，可逐项选择移入废纸篓；样本未生成 SymbolCache，因此它保持只读。移入废纸篓前会复核路径身份、内容、近期修改和进程占用；见[验证记录](docs/XcodeCacheValidation.md)。取消扫描、不可读目录或符号链接会以不完整结果反馈。
- 卸载应用包，并查找当前用户资源库中与应用包标识精确匹配的文件；支持选择或拖入 `.app` 审阅。
- 从部分用户资源库数据目录列出疑似卸载残留供人工核实；会排除已安装应用及其扩展、服务和登录项的包标识。由于无法只凭名称确认归属，残留候选保持只读，不扫描偏好设置和日志作为残留依据。
- 扫描时显示阶段、已处理数量和当前位置；完成后显示扫描来源、结果数量、可清理数量、遗漏与警告提示，并说明大小估算的含义。切换页面后保留各分类的扫描与结果。
- 已扫描结果支持搜索、排序、类型与可清理状态筛选和快速预览；重复文件可按组选择并长期忽略指定组。可在设置中排除下次扫描的路径。
- 逐项展示候选原因，默认移入废纸篓、单独提供永久删除，并保存本机清理记录；可从记录中恢复由本应用移入废纸篓且仍可核对的项目，恢复不会覆盖原路径已有文件。
- 在 Finder 中右键单个 `.app`，从“服务”选择“使用 Sys Cleaner 查看应用”，即可打开应用卸载页审阅。
- 菜单栏常驻图标；关闭主窗口后可从菜单栏重新打开，或通过菜单退出应用。
- 设置支持即时切换中英文、跟随系统／深色／浅色外观、六款程序坞与菜单栏图标，并提供关于信息；选择会在重启后保留。
- 全程本地扫描；没有账号、遥测、定时清理、提权助手或常驻监控。

## 构建与测试

使用 Xcode 打开 `SysCleaner.xcodeproj`，运行 **Sys Cleaner** scheme。命令行可执行：

```sh
swift test
xcodebuild -project SysCleaner.xcodeproj -scheme 'Sys Cleaner' -configuration Debug \
  -derivedDataPath DerivedData CODE_SIGNING_ALLOWED=NO build
```

工程文件已包含在仓库中。新增 Swift 文件后，可用 `ruby scripts/generate-project.rb` 重新生成；此步骤需要 Ruby 的 `xcodeproj` gem。

## 权限与清理规则

空间分析、大文件和重复文件从用户选择的文件夹扫描。缓存和卸载功能只读取明确列出的本机位置。访问受保护目录可能需要用户在“系统设置 → 隐私与安全性 → 完整磁盘访问权限”中自行授权；拒绝授权后仍显示可访问的结果，并报告未完成扫描的位置。

所有删除项目都必须先显示并由用户勾选。执行前再次检查文件身份、大小、修改时间、路径边界、符号链接、云端占位及保护目录。最近 15 分钟修改的缓存、`lsof` 显示正在使用的文件、运行中的应用，以及扫描后内容变化的应用包会被跳过。DerivedData 以整个项目目录为单位，仅可移入废纸篓；删除前复核内容和占用状态，只有 Xcode 元数据确认来源时才显示项目路径。归档只读。模拟器只允许删除已关闭设备，执行前重新检查状态并单独确认；通过 `simctl` 删除的设备数据不能从废纸篓恢复。移入废纸篓失败不会自动改为永久删除。

逻辑大小和已分配磁盘块大小分别显示。APFS 克隆、稀疏文件或共享存储会使实际释放空间不同；清理结果也会显示卷可用容量的观测变化，其中可能包含其他活动。扫描结果会标明不可读位置或项目上限导致的不完整情况。空间分析页只读，大于零且小于 1 MB 的文件合并显示为“其他文件”，但仍计入文件夹总量；饼图显示容量最大的 6 个非零项目，其余项目与原有“其他文件”合并为“其他”扇区，零容量项目最多单独列出 10,000 项。重复文件扫描跳过符号链接、硬链接和云端占位文件，每组保留一份不可勾选的副本。缓存页显示体积最大的 2,000 个文件，重复比较最多处理 100,000 个文件，超限时显示提示。应用卸载页先快速列出应用，再在后台逐项计算包内大小；打开应用详情后审阅关联文件并勾选。运行中的应用需退出并重新扫描。旧版本清理记录、永久删除的项目及废纸篓中已变化的项目无法通过记录恢复。不清理系统根目录、系统快照、iCloud 云端原件或应用归档；iCloud Drive 页仅允许移除已安全同步的本机副本，模拟器设备删除需单独确认。

Xcode 审阅清单会在清理前后复扫并逐类对比数量及逻辑大小估算；扫描不完整时不把数字当成可靠变化，手动重扫或离开页面会清除对比。结果逐项区分成功、安全跳过与操作失败并说明原因；跨卷批量操作不显示单一卷的容量差值。

## 源码开源与可选的直接分发

目前仅在 GitHub 开源源码，不提供可下载的 App 二进制。可按上面的命令在本机自行构建。

如果将来提供直接下载的 App，Release 构建启用 Hardened Runtime，未启用 App Sandbox。准备 Developer ID Application 证书及 `notarytool` 钥匙串配置后，设置 `TEAM_ID`、`DEVELOPER_ID_APPLICATION` 和 `NOTARY_PROFILE`，执行 `zsh scripts/release.sh`。脚本会归档、签名、公证、装订、验证并生成 `build/release/Sys-Cleaner.zip`。只有使用真实签名身份完成全部验证后，才将二进制产物视作可分发版本。
